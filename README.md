Wazuh Security Monitoring

Author: Sulayman Sanyang

Project Overview

This project demonstrates the use of Wazuh for security monitoring and threat detection in a Windows 11 virtual machine environment.

The project focuses on collecting and analyzing Windows security events and detecting important security activities using Wazuh.

Objectives

* Configure Wazuh to monitor a Windows 11 system.
* Collect Windows security event logs.
* Detect failed login attempts and account-related activities.
* Monitor process creation and PowerShell activity.
* Detect account lockouts and privilege-related events.
* Analyze security alerts generated by Wazuh.

Tools and Technologies

* Wazuh
* Windows 11
* UTM Virtualization
* Windows Event Logs
* PowerShell
* Security Event IDs

Security Events Tested

The following Windows security events were successfully tested and monitored:

* 4625 — Failed Logon
* 4720 — User Account Created
* 4726 — User Account Deleted
* 4688 — Process Creation
* 4104 — PowerShell Script Block / Process Discovery
* 4740 — Account Lockout
* 4672 — Special Privileges Assigned
* 4719 — Audit Policy Change

Conclusion

This project provided practical experience with security monitoring, Windows event logging, and the detection of suspicious or important security activities using Wazuh.

It also demonstrated how a Security Information and Event Management (SIEM) platform can be used to monitor and investigate events occurring on a Windows system.
